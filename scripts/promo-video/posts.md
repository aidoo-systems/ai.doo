# Posting the promo videos

File names are `render.mjs` output in `out/`. Every claim below is on `/promo-games/` or
`/stamps/`; keep replies to the same claims (no "boosts sales", no "stamps on sale now").

## Which video goes where

| Account | Pour game | Stamp card |
|---------|-----------|------------|
| Instagram (Reel) | `pour-short-9x16.mp4` | `stamps-short-9x16.mp4` |
| TikTok | `pour-short-9x16.mp4` | none |
| YouTube Shorts | `pour-short-9x16.mp4` | none |
| Facebook (as a Reel) | `pour-full-9x16.mp4` | `stamps-full-9x16.mp4` |
| LinkedIn | `pour-full-16x9.mp4` | `stamps-full-16x9.mp4` |

- No stamps on TikTok or Shorts: the pilot is for a few Island shops, and those audiences mostly aren't.
- Spares: `pour-short-16x9` and `stamps-short-16x9`, for the website or X.
- Per-shop stamps videos (`--shop`) go in that shop's email only.
- Pour first, stamps three or four days later.
- Add a quiet track from the app's own library on Instagram, TikTok and Shorts; the videos are silent.
- Instagram and TikTok allow one bio link: `aidoo.biz/promo-games` for the pour week, then `aidoo.biz/stamps`.
