Privacy Policy — Reactor Panic

Last updated: October 2026

Reactor Panic is a mobile game built in Godot. This policy explains what data the game collects and how it is used. Our website: https://www.aidoo.biz.

Data we collect

The game uses a developer-hosted leaderboard service. The data sent to the leaderboard is:

  • Persistent anonymous player ID
  • Optional display name (user-editable)
  • Score
  • Run duration
  • Difficulty
  • Timestamps for leaderboard entries

If something goes wrong (for example, the leaderboard cannot be reached), the game sends a short error report to the same developer-hosted service: the anonymous player ID, the game version, the platform, and a description of the error.

Analytics (Google Firebase)

The Android version uses Google Firebase Analytics to understand how many players come back and how long sessions last. It records app opens and sessions, when a run starts and ends (score, time survived, game mode, difficulty, and whether a continue was used), and when the tutorial is finished. Firebase also collects device information (such as model, operating system and country) and an app-instance identifier. It does not receive your display name, and we do not use it for advertising. Google processes this data under its privacy policy; see also Firebase privacy information.

Data we do not collect

We do not collect location, contacts, photos, microphone, camera, or payment data. There are no ads, and Firebase Analytics is the only third-party SDK that receives data.

How we use data

We use the data above to operate leaderboards, display rankings, and keep scores tied to a consistent anonymous player ID. We use error reports to fix problems, and analytics to see whether players return and which parts of the game need work.

Storage and security

Leaderboard data and error reports are stored on servers hosted and managed by the developer. Analytics data is stored by Google Firebase. Data is sent over encrypted connections.

Data sharing

We do not sell or rent your data. The only third party that receives data is Google, which processes the analytics described above on our behalf.

Data retention

Leaderboard entries are kept for as long as the leaderboard service is available. You can request deletion at any time using the contact details below. Firebase Analytics data keeps event-level data for no more than 14 months.

Your control

You can change or clear your display name at any time in the game. If you want your leaderboard data removed, contact us and we will delete it.

Children's privacy

Reactor Panic is a general-audience game and is not directed at children under 13. We do not knowingly collect personal information. If you believe a child has provided personal information, contact us and we will remove it.
